Normative modelingof neuroimaging data using generalized additive models of location scale and shape (https://www.biorxiv.org/content/10.1101/2021.06.14.448106v1), using the package PCNtoolkit (in Python). 
The work implements Bayesian Hierarchical Regression with adaptive HMC (NUTS sampler from PyMc3) for generalized additive models of location scale and shape (GAMLSS).
We also performed model comparison using Bayesian criteria.
